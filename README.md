# Gestión de Datos de Países en Python (TPI - Programación 1)

Este proyecto es el Trabajo Práctico Integrador (TPI) para la Tecnicatura Universitaria en Programación (UTN FRM). La aplicación permite gestionar información demográfica y geográfica de diversos países aplicando persistencia de datos mediante archivos CSV, algoritmos de búsqueda/ordenamiento y cálculo de estadísticas clave.

## ⚙️ Características y Funcionalidades
1. **Alta de países:** Validación estricta para impedir entradas vacías o datos negativos.
2. **Actualización:** Modificación de valores numéricos (Población y Superficie).
3. **Búsqueda flexible:** Búsqueda por fragmentos o cadenas completas.
4. **Filtros avanzados:** Filtrado por continente, rangos de población y superficie.
5. **Ordenamientos:** Criterios múltiples (Ascendente / Descendente).
6. **Estadísticas:** Indicadores de máximos, mínimos, promedios y distribución por continente.
